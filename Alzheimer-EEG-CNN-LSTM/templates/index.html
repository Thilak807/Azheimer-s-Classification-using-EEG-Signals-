System Highlights & Pipeline Architecture

Seamless end-to-end framework from raw electrophysiological recordings to clinical classification.

1. EEG Signal Processing

Applies 0.5–45.0 Hz bandpass filtering, 50 Hz power line notch filtering, 128 Hz resampling, and channel-wise Z-score normalization across 19 standard scalp channels.

  • 10-20 Standard Electrode Layout
  • Artifact Clipping & Standardization

2. CNN-LSTM Deep Model

1D Convolutional layers extract localized spatial and morphological wave patterns, while Bidirectional LSTM layers model long-range temporal sequence dependencies.

  • Multi-Scale 1D Conv Kernels (7, 5, 3)
  • Bidirectional LSTM Temporal Memory

3. Zero-Leakage Evaluation

Evaluated across 50/50, 80/20, and 20/80 splits with strict subject-level isolation so that windows from the same patient never appear in both train and test sets.

  • Balanced Class Weighting
  • Accuracy, Precision, Recall, F1
